# TradeSphere Security Notes

TradeSphere includes some experimental security-related utility files for learning and project enhancement.

## Included Security Utilities
- `generate_keys.php`
- `make_hash.php`

## Purpose
These files were created to explore:
- RSA key generation
- hashing
- digital signature related workflows
- secure communication ideas for future chat or transaction verification

## Current Use
These files are currently part of the development and experimentation phase of the project. They are stored separately from the main application flow so the core system remains clean and easy to manage.

## Note
These scripts are not required for the basic e-commerce flow, but they are included to show the project’s extended security direction and experimentation.
