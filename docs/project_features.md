# TradeSphere Project Features

## Core Features

- User registration and login
- Product listing for sellers
- Product browsing for buyers
- Add to cart functionality
- Seller can mark items as sold
- Sold items can appear in cart as unavailable
- Profile dropdown and floating cart interface

---

## Extended / Development Features

- Sample data generation
- RSA key generation experimentation
- Hash generation experimentation
- Recommendation system preparation

---

## Marketplace Features

TradeSphere supports a multi-vendor marketplace system where a single account can act as both:

- Buyer
- Seller

Additional marketplace features:

- Product category browsing
- Product image upload
- Product search system
- Product filtering
- Wishlist system
- Seller dashboard
- Purchase history
- Received orders section
- Completed sales tracking
- User profile dashboard

---

## Payment Features

TradeSphere currently supports:

- eSewa payment integration
- Payment success workflow
- Digital bill generation
- Transaction logging

Planned:

- Khalti integration
- Multiple payment methods

---

## Chat and Communication Features

TradeSphere includes a buyer–seller communication system:

- Product-specific chat rooms
- Floating message interface
- Read/unread message states
- Message notifications
- Quick message suggestions
- Pinned product cards
- Product discussion before and after purchase

---

## Offer & Negotiation Features

TradeSphere includes a negotiation workflow:

- Buyer can make offers
- Seller can accept offers
- Seller can reject offers
- Accepted offers become pinned
- Negotiated price can be directly added to cart
- Checkout supports negotiated pricing

---

## Notification System

Features include:

- Notification bell
- Read/unread notification handling
- Floating message counters
- Order notifications
- Delivery notifications
- Chat notifications

---

## Order Tracking Features

Order workflow:

Processing
↓
Out For Delivery
↓
Delivered

Buyer and seller receive updates throughout the process.

---

## Recommendation System Preparation

Recommendation logic experimentation includes:

- viewed products
- cart history
- product similarity
- purchase history
- category matching
- cosine similarity concepts
